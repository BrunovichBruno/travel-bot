# Travel Bot — автопостинг в Telegram с рерайтом

Бесплатный бот, который парсит русскоязычные RSS-ленты про путешествия,
переписывает текст через бесплатный тариф Google Gemini (чтобы не постить
чужой текст один в один) и публикует в ваш Telegram-канал. Работает через
GitHub Actions — никакой сервер не нужен.

## Источники по умолчанию

- `lenta.ru/rss/news/travel` — официальная RSS-лента рубрики «Путешествия»
  Ленты.ру
- `lenta.ru/rss/articles/travel` — статьи той же рубрики
- `ria.ru/export/rss2/index.xml` — общая лента РИА Новости, отфильтрованная
  по ключевым словам про туризм (см. `KEYWORDS` в `bot.py`)

Можно добавить любой другой русскоязычный источник с RSS — просто впишите
ссылку в список `RSS_FEEDS` в `bot.py`.

## Шаг 1. Создайте Telegram-бота и канал

1. В Telegram напишите **@BotFather**, команда `/newbot`, следуйте инструкциям.
   В итоге получите **токен** вида `123456789:ABCdefGhIJKlmNoPQRstuVwxyZ`.
2. Создайте канал (если ещё нет), сделайте бота **администратором** канала
   (права на публикацию сообщений).
3. Узнайте ID канала:
   - Публичный канал — используйте юзернейм: `@my_travel_channel`.
   - Приватный канал — перешлите любое сообщение из канала боту
     [@userinfobot](https://t.me/userinfobot) или получите числовой ID вида
     `-1001234567890` через `getUpdates`.

## Шаг 2. Получите бесплатный ключ Gemini (для рерайта)

1. Откройте https://aistudio.google.com/apikey (нужен обычный Google-аккаунт,
   банковская карта не требуется).
2. Нажмите **Create API key**, скопируйте ключ.
3. Бесплатный тариф Gemini ограничен по количеству запросов в минуту/день —
   для 3 постов раз в 2 часа этого более чем достаточно.

Если пропустить этот шаг — бот будет работать и без рерайта, просто
публиковать заголовок и описание из RSS как есть.

## Шаг 3. Загрузите проект на GitHub

1. Создайте новый **приватный** репозиторий на GitHub.
2. Загрузите файлы `bot.py`, `requirements.txt`, `posted.json`, `README.md`
   и папку `.github` (через веб-интерфейс: "Add file → Upload files").

## Шаг 4. Добавьте секреты

**Settings → Secrets and variables → Actions → New repository secret**

- `TELEGRAM_BOT_TOKEN` — токен бота из шага 1
- `TELEGRAM_CHANNEL_ID` — юзернейм или ID канала из шага 1
- `GEMINI_API_KEY` — ключ из шага 2 (опционально, но рекомендуется)

## Шаг 5. Запустите

Workflow запускается автоматически каждые 2 часа. Чтобы проверить сразу:

**Actions → Автопостинг в Telegram-канал → Run workflow**

## Как работает рерайт

Для каждой новости бот отправляет в Gemini заголовок и описание из RSS с
инструкцией переписать своими словами, без дословного копирования и без
выдумывания фактов. Модель возвращает JSON `{"title": ..., "text": ...}`,
который используется для поста. Если ключ Gemini не задан или запрос не
удался — бот подстрахуется и опубликует оригинальный (очищенный от HTML)
текст из RSS.

## Настройка под свою нишу

Откройте `bot.py`:

- `RSS_FEEDS` — список источников.
- `KEYWORDS` — ключевые слова фильтрации (важны для общих лент вроде ria.ru).
- `MAX_POSTS_PER_RUN` — сколько постов за один запуск.
- `HASHTAGS` — хэштеги под постом.
- `REWRITE_PROMPT` — промпт для Gemini, можно поменять стиль/тон канала.
- `GEMINI_MODEL` — модель Gemini (по умолчанию `gemini-2.0-flash`; если
  название модели устареет, актуальный список бесплатных моделей смотрите на
  https://ai.google.dev/gemini-api/docs/models).

## Важно про авторские права

Рерайт снижает риски, но не отменяет правило: всегда указывайте источник
(это уже встроено в шаблон поста) и не убирайте ссылку на первоисточник.

## Дальнейшие улучшения (по желанию)

- **Модерация перед публикацией**: замените `TELEGRAM_CHANNEL_ID` на свой
  личный chat_id для тестового прогона перед тем, как включить постинг в
  канал напрямую.
- **Больше источников**: добавьте RSS других русскоязычных изданий — просто
  проверьте, что лента открывается в браузере и отдаёт валидный XML.
- **Растянуть публикацию по дню**: добавить случайную задержку между
  запусками вместо жёстких 2 часов.
